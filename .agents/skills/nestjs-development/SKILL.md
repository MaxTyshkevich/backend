# Архитектура backend

Процесс задаёт [AGENTS.md](../../../AGENTS.md), навигацию — [backend-workflow](../backend-workflow/SKILL.md). Для самостоятельных задач о документации или Git этот технический навык не требуется.

Перед решением проследи запрос до БД, определи владельца ресурса и зависимости. Версии бери из package.json и lock-файла. Существующая структура описывает текущее поведение, но не обязывает повторять её недостатки.

Для затронутой части прочитай соответствующий раздел [architecture.md](references/architecture.md): ресурсы и модули, HTTP и DTO, доступ или конкурентные операции. При смешении обязанностей предложи разделение в плане; не расширяй задачу без согласования.

Сохраняй Prisma, PostgreSQL и cookie-сессии. Новые слои и зависимости оправдывай конкретной потребностью. При рефакторинге сверяй URL, статусы, JSON, headers, Guards и DI; успешной сборки недостаточно. Спорные API проверяй по официальной документации для установленной версии.
